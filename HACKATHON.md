# Nebius x NVIDIA Global AI Hackathon — Brief

Build a working AI system on open, independent infrastructure: NVIDIA open source models served on Nebius (Token Factory or AI Cloud).

## Hard requirements
- Runs on **Nebius Token Factory** or **Nebius AI Cloud**.
- Uses **at least one NVIDIA open source model** (Nemotron family: Nano / Super / 3 Ultra; also GROOT, Cosmos, Sonic for Physical AI).

## Tracks (pick one)
| Track | Focus | Suggested tooling |
|---|---|---|
| Coding & Agentic Engineering | Coding agents / dev tools that write, run, and test code in Token Factory | Token Factory |
| Best Apps & Agents | Any app/agent people would actually use (copilot, productivity, self-running workflow) | Nemotron 3 Ultra for heavy reasoning, Nano/Super for fast everyday calls; Nebius Serverless Endpoints / Serverless Jobs encouraged (optional) |
| Personal AI | Always-on private assistant, user controls the data; persistent memory, reusable skills, chosen tools, cross-workflow tasks | NVIDIA NemoClaw, OpenShell, Hermes Agent, Nebius Serverless |
| Physical AI | Embodied/edge agents: robotics, IoT, on-device | Nemotron, GROOT, Cosmos, Sonic; Serverless Jobs for sim/synthetic data/policy eval; Serverless Endpoints for real-time inference. Video needs ≥1 min of hardware operating (or key modules if no hardware) |

- [ ] README: setup + run instructions; how Nemotron/NVIDIA models are used; where Token Factory helped; other Nebius services used

## Judging criteria
1. **Technological implementation** — how well built; how effectively it uses Token Factory / AI Cloud and Nemotron.
2. **Design** — complete, coherent product experience, not just a proof of concept.
3. **Potential impact** — credible, specific case for a real problem and real audience, backed by what's demonstrated.
4. **Quality of the idea** — creative, non-obvious use of Token Factory + Nemotron; real understanding of the problem space.
